# Эволюция ИКТ — 3D презентация (Next.js + Three.js)

Полёт камеры внутри 3D-скана модуля МКС. Каждый из 10 слайдов — отдельный ракурс.

## Запуск
```
npm install
npm run dev      → http://localhost:3000
# или продакшн:
npm run build && npm start
```

## Управление
- Скролл / колесо / свайп — слайды
- ← → ↑ ↓, PageUp/PageDown, Space — переход; Home / End — первый / последний
- **A** — автопоказ (каждые 9 секунд), **F** — полный экран
- Мышь — лёгкий «взгляд по сторонам» + наклон карточки
- Точки справа — прыжок на любой слайд

## Что внутри
- `lib/path.js` — маршрут камеры: 10 ракурсов (функция `shot(z, yaw, pitch, roll, fov)`),
  сплайн-интерполяция между ними. Ось модуля захардкожена, камера всегда внутри.
- `lib/slides.js` — тексты, «факты» и подписи секторов HUD.
- `components/Presentation.jsx` — сцена: звёзды, пыль в невесомости, «варп»-FOV при перелёте, HUD.
- `app/globals.css` — оформление.

Модель: `public/model/spaceship.obj` (38 МБ, первая загрузка занимает несколько секунд).
